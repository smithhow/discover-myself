## “发现自己”方案：**完全离线、无后端**
―― 让 **手机/电脑** 成为“自给自足”的评测与成长平台

---

### 1️⃣ 核心思路

| 目标 | 实现方式 |
|-----|-----------|
| **完整数据保存在设备本地** | ① 数据库：SQLite / IndexedDB<br>② 加密：AES‑256 + PIN / TouchID/Fingerprint/FaceID |
| **游戏化与正向反馈** | ① 本地资源包：题库、模型、动画、徽章、抽奖数据<br>② 即时动画/音频 **（PWA/Web Audio 或原生音频）** |
| **奖品与成就** | ① 奖品（兑换券、徽章、积分）保存在本地，抽奖由本地随机数决定（可由用户设置种子或用设备时钟）<br>② **无网络时的“抽奖”**：采用局部随机算法，返回对应奖励 |
| **跨设备同步（可选）** | ① 用户可手动导出/导入备份文件（JSON/ZIP）<br>② 按需启用轻量同步（仅同步日志、成就，不上传答题） |
| **安全与合规** | ① 所有数据本地加密，解密密钥只存放在设备存储或“安全箱”<br>② 无需托管服务器，天然符合 GDPR/中国网络安全法 |

> **关键词**：离线优先、隐私至上、简单、可迭代

---

## 2️⃣ 技术架构

| 层 | 技术 | 说明 |
|---|---|---|
| **UI/交互** | React Native / Flutter（原生跨平台）<br>或 PWA（Progressive Web App）<br>+ HTML5 + CSS3 | 体验像游戏、动画流畅、可离线 |
| **本地数据库** | – Android/ iOS SQLite<br>– Web IndexedDB / WebSQL | 结构化存储：用户、测评记录、成长树、积分、徽章、抽奖日志 |
| **加密** | ① AES‑256‑CBC + PBKDF2（PIN/指纹）<br>② Keychain/Keystore/Web Crypto APIs | 密钥仅保存在设备 |
| **模型与算法** | - 题库 & 评分公式：JSON <br> - 统计模型：Python‑Pickle 或 wasm‑packaged | 可全离线运行，无需 fetch |
| **媒体资源** | PNG/SVG/MP3/GLTF/Flare 预打包 | 锦标、动画、音效、背景音乐 |
| **抽奖机制** | ① 本地 PRNG（Mulberry32/alea）<br> ② 加权候选表存储 | `seed = timestamp + deviceId` → 可验证 |
| **备份/同步** | ① 导出/导入 JSON/ZIP <br> ② 可选 OAuth/SFTP 等网传（不强制） | 只做 **数据备份**，不做大规模汇总 |

> **注**：鉴于后端已不再存在，所有“后台”功能（如服务器同步、排行榜、跨设备领取）均转移至本地实现，或完全排除。

## 3️⃣ 主要功能实现细节

| 模块 | 关键实现 | 离线策略 |
|------|----------|----------|
| **测评车程** | 1. 每道题带**参考答案**/权重<br>2. 评分算法自定义（文本 + 计算式） | 题库全部预打包，评分原程在前端计算 |
| **结果反馈** | ① 层级面板（星盘、成长树）<br>② 实时动画 “你完成了 70% 的成长任务” | 所有可视化资源与数据在 local storage |
| **奖励/积分** | ① 积分系统（满分 1000）<br>② 徽章徽章：本地 QR / 图像 <br>③ 抽奖：使用本地 PRNG 选取奖品 | 抽奖算法完全不需网络，奖品库存固定 |
| **成长建议** | ① 基于 5 位维度 + 职业兴趣，匹配 **岗位表**（本地 JSON）<br>② 可下载 **PDF 报告**（离线生成） | 所有规则与数据在 app 内含 |
| **番外篇** | ① MBTI、星座、16Personalities 免费版 | 题库 + 诠释 本地包含 |
| **社群 / 排行** | 可选：**仅本机**排行榜与成就显示；不与外部服务器同步** | 可手动分享截图、导出文件 |
| **美容化妆** | 每道题结束时弹出互动动画（如拆卡动画）、音效 | 所有资源预打包 |

## 4️⃣ 关键安全与隐私要点

| 项目 | 对策 |
|------|------|
| **数据加密** | AES‑256 加密数据库 + PIN/生物识别获取密钥 |
| **密钥存储** | iOS: Keychain, Android: Keystore, Web: IndexedDB + crypto.subtle |
| **备份安全** | 导出的备份文件加密，仅用户知晓的密码还能解 |
| **网络请求** | 所有外部请求仅为 **可选同步**，不会主动发送对个人数据的查询 |
| **合规** | 本地存储国情合规（不将 user_id 带给服务器），可手动删除数据 |

---

## 5️⃣ 可能的不足与缓解方法

| 限制 | 说明 | 缓解 |
|------|------|------|
| **多设备同步受限** | 同一账号在多台设备之间无法同步历史 | 提供“手动导入/导出备份”方式；或者启用轻量后台同步（可选） |
| **缺乏社会竞争力** | 不能做公开排行榜、社群成就 | 可用本机排行榜并导出截图分享 |
| **抽奖公平性** | 只在本地随机，无法复核 | 使用设备时钟 + 用户ID 生成种子，结果可通过 “导出抽奖日志” 供人工验证 |
| **新功能迭代** | 必须发布新版本才能给用户新题库/模型 | 通过 **增量更新包**（只下载新增题库/模型）保持更新 */

## 6️⃣ 快速 MVP 代码目录结构（示例）

```
app/
├─ src/
│   ├─ components/             # UI 组件
│   ├─ data/
│   │   ├─ questions.json      # 题库
│   │   ├─ models.json        # 评分公式
│   │   ├─ prizes.json        # 抽奖库
│   │   └─ recommendations.json
│   ├─ db/
│   │   └─ database.js         # SQLite/IndexedDB 封装
│   ├─ encryption/
│   │   └─ crypto.js          # AES 加解密
│   ├─ services/
│   │   ├─ assessment.js      # 评分逻辑
│   │   ├─ achievement.js    # 积分、徽章
│   │   └─ lottery.js        # 抽奖算法
│   └─ utils/
│       └─ random.js         # 可重现 PRNG
├─ assets/
│   ├─ images/
│   └─ sounds/
└─ index.html (PWA) / App.js (ReactNative)
```

> **提示**：所有 JSON 资源均打包进应用内部，任何地方可离线读取；所有计算均在前端完成，无网络延迟。

### 结语

- **完全离线** → 你可以拥有 **最小化网络参与、最高级私密** 的自我评测游戏。
- 只要在设计前做好 **加密、离线资源** 的打包，就可以直接在手机上跑完整流程。
- 若将来想再 / 加 *少量* 后端（比如仅是大屏落地的排行榜），可以后面再轻量添加。
